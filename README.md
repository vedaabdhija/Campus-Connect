# 🎓 Campus-Connect

Campus-Connect is a web-based student attendance management system designed to simplify attendance tracking and provide an organized dashboard for managing student records.

## 📌 Features

- 👩‍🎓 Student attendance management
- 📊 Attendance dashboard
- 🗂️ Student record management
- 💾 Persistent data storage using SQLite
- 🌐 Web-based interface
- 📱 Simple and user-friendly interface

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **HTML**
- **CSS**
- **JavaScript**
- **SQLite**
